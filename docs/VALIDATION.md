# Validation Guide

All examples generated by UniProp must pass rigorous validation gates before being flushed to Parquet.

## Implemented Quality Gates

The `src/validation/validators.py:validate_example` function checks:
- **Option-Count Validation**: Asserts counts fall between `[2, 40]`.
- **Label Validation**: Enforces `sum(labels) == 1` for single-choice tasks.
- **Contradiction Detection**: Detects mutually exclusive logical relations (e.g. `above` vs `beneath`) and blocks contradictory multi-labels.
- **NONE Validation**: Asserts that if a `NONE` proposition is True, all other labels are False.
- **Grammar & ID Checking**: Rejects unresolved IDs (e.g. `o12`) and bad grammar.

## Execution
Validation runs automatically inline during generation inside `main_pipeline.py`.
